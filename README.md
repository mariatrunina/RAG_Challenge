Данный проект представляет собой реализацию пайплайна RAG, разработанного для автоматического извлечения данных из файлов в рамках соревнования. Система использует векторный поиск и языковую модель Llama 3 через API Groq.

Основные возможности
Парсинг: Обработка PDF-документов с разбивкой на смысловые фрагменты (чанки) для точного поиска.
Векторный поиск: Использование модели эмбеддингов для глубокого семантического поиска в базе из более чем 39 000 векторов.
Оптимизация под Groq: Внедрена логика управления лимитами (TPM/RPM), обход ошибки 413 (Request too large) и автоматические повторы запросов.
Система чекпоинтов: Автоматическое сохранение прогресса в temp_results.json, позволяющее продолжать работу после сбоев без потери токенов.
Строгая валидация: Формирование итогового JSON в строгом соответствии со схемой.

Технологический стек
LLM: Llama-3.1-8b-instant (через Groq API).
Vector Store: Векторная база данных с поддержкой поиска по сходству.
Embeddings: Multilingual E5 Large.
Язык: Python 3.10+.
Библиотеки: groq, sentence-transformers, re, json.

Структура проекта
main.py — точка входа, управление циклом пайплайна и финальная сборка сабмита.
query_processor.py — управление промптами, логика взаимодействия с LLM и очистка ответов.
vector_store.py — интерфейс для работы с векторным индексом и поиска контекста.
configuration.py — централизованное управление настройками и путями.

Логика обработки
Система проходит три этапа очистки ответа модели:
Промпт-инжиниринг: Ролевая модель "Финансовый аналитик" для точного извлечения цифр.
Типизация: Автоматическое приведение ответов к типам boolean (True/False) и number (float/int).
Форматирование: Перевод текстовых числительных в стандартные числа.

Результат
Пайплайн успешно проходит валидацию на сервере со статусом valid submission. Система устойчива к лимитам бесплатного Groq и обеспечивает корректную привязку ссылок на документы и страницы.
